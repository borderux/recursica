# Flex Implementation Notes

The `Flex` component is a generic unopinionated flex layout wrapper mapped directly to Mantine's `Flex`.
It currently does not require any custom logical layouts or CSS workarounds since it serves only to provide absolute, raw manipulation of standard CSS flex properties. All spacing props (gap, align, justify, direction, wrap) pass safely through via the `filterStylingProps` layout-property allowance, with `rec-` dimension tokens scaling transparently mapped to standard gap limits.

The layout props (direction, align, justify, wrap, gap, rowGap, columnGap) additionally accept per-breakpoint responsive objects, typed against the framework-agnostic `Responsive<T>` helper in `@recursica/adapter-common`. This shape deliberately mirrors Mantine's own `StyleProp<T>`, so intersecting `RecursicaFlexProps` with `MantineFlexProps` keeps the responsive form intact instead of collapsing it to a bare scalar (which would otherwise reject `direction={{ base: 'column', xl: 'row' }}`). At runtime Mantine handles the responsive objects natively, so they pass straight through; the only added logic is `rec-` token resolution, which now recurses one level into responsive objects so that `gap={{ base: 'rec-sm', xl: 'rec-lg' }}` maps each breakpoint value transparently just like a scalar. Note that responsive support is per-component: Flex types all of these props as Mantine `StyleProp`s, and Grid's gutter is likewise responsive, but Mantine's Stack and Group type `gap`/`align`/`justify`/`wrap` as single values — so on those components only the margin props (which map to Box style props) accept responsive objects.

The shared `Responsive<T>` helper keys its breakpoint object as `RecursicaBreakpoint | (string & {})`, mirroring Mantine's `StyleProp` key (`MantineBreakpoint | (string & {})`). The literal `RecursicaBreakpoint` union drives editor autocomplete, while the `(string & {})` half means custom breakpoint names a consumer adds through Mantine's `MantineThemeSizesOverride` module augmentation type-check on Recursica-typed props too (e.g. Grid's `gap` and the margin props), keeping the type layer in step with what Mantine actually resolves at runtime from `theme.breakpoints`.
