DatePicker's calendar (hover, today, weekend, disabled/outside days, in-range, header nav/month-label as Recursica text buttons, popover border/shadow) is now fully token-driven. Default value format is `MM/DD/YY`, `highlightToday` defaults to `true`, a default calendar icon is provided (overridable via `leftSection`), and the field no longer wraps its value/placeholder to a second line. Default placeholder is `"MM / DD / YY"` (overridable via `placeholder`).
